# AGENTS.md

## Mission
Build and ship SurplusSlot as a complete, runnable MVP. Do not stop at scaffolding.

## Execution Rules
- No partial implementations for accepted scope.
- If assumptions are required, document them in `docs/ASSUMPTIONS.md` immediately.
- Every feature must include docs updates and at least one validation path (manual or automated).
- Do not silently skip failing quality gates.
- Keep changes small and coherent; prefer predictable conventions over cleverness.

## Done Means Done
- App runs from clean clone with documented commands.
- Core flow works end-to-end: merchant creates offer -> customer places order -> pickup confirmed.
- Critical tests pass.
- API and environment docs are updated.
- Seed data is available.
